## Proyecto destacado

### [`droid-skills`](https://github.com/CursosDroid/droid-skills)

Un marketplace open source de skills para Claude Code especializado en Android moderno y Kotlin Multiplatform.

Incluye flujos para revisar pull requests, crear pantallas con Compose, analizar el manejo de estado, planificar migraciones a KMP, revisar migraciones de Room y mantener Gradle bajo control.

```bash
# Añade el marketplace
claude plugin marketplace add CursosDroid/droid-skills

# Instala el plugin
claude plugin install cursosdroid-android
```
